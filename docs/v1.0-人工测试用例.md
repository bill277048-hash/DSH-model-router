### 0.3 判定标准说明

| 标记 | 含义 |
| --- | --- |
| **PASS** | 完全符合预期 |
| **FAIL** | 与预期不符 → **必须上报** |
| **OBSERVE** | 记录现象即可，不算缺陷（如耗时、数据量）|

**FAIL 的硬性红线**（出现任一即视为**严重缺陷**）：
- 任何端点返回 **5xx**
- 对话出现**卡死 / 无响应 / 丢字**
- 面板出现**白屏 / 报错弹窗**
- 配置改动后**重启丢失**
- `state.json` 或档案文件**损坏**

**步骤**：
